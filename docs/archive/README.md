decisions, and upstream research that would be expensive to reconstruct. They are **not** current
operational guidance:

- Current user instructions: [user guide](../USER_GUIDE.md)
- Current hosting and security guidance: [administrator guide](../ADMIN_GUIDE.md)
- Current development process: [developer guide](../DEVELOPER_GUIDE.md) and
  [CONTRIBUTING.md](../CONTRIBUTING.md)
- Current behavior contracts: [`openspec/specs/`](../../openspec/specs/)
- Current test count and project status: [documentation index](../README.md)

Notes:

- Test counts inside these reports describe the day they were written. The live count is tracked in
  [the documentation index](../README.md).
- Findings that were later resolved carry inline “superseded/noted” dates rather than being
  rewritten, so the record of what was true at the time stays intact.
- Upstream issue state is frozen at the audit date; local status may have moved since.
- Links in these documents were adjusted only to keep them working after the move; their content is
  unchanged.
